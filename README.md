# AI vs. Human Text Detector

An end-to-end Machine Learning and Natural Language Processing (NLP) application that evaluates whether a given body of text was written by a **Human** or generated by **AI** (ChatGPT). This repository powers the live [Streamlit Web Application](https://ai-vs-human-text-detector-7ek6usxjr3oiyxhylj9398.streamlit.app/).

---

## 1.Project Overview

As large language models become ubiquitous across industries, distinguishing between human-authored text and machine-generated content is critical for education, publishing, and automated moderation. 

This project trains a high-performance classification pipeline using the **HC3 (Human ChatGPT Comparison Corpus)** dataset, turning raw textual data into TF-IDF n-gram features and leveraging a Logistic Regression classifier to predict origin with real-time confidence scores.

---

## 2.Features

- **Automated Text Cleaning:** Strips boilerplate AI conversational prefixes (e.g., *"As an AI language model..."*) and normalizes whitespace.
- **TF-IDF Feature Engineering:** Extracts important unigrams and bigrams (`ngram_range=(1, 2)`) up to 5,000 maximum features.
- **Fast Inference UI:** Built with Streamlit, featuring loading spinners, validation warnings for short texts, and intuitive confidence metrics with visual progress bars.
- **Cached Pipeline Optimization:** Utilizes Streamlit's `@st.cache_resource` to ensure the dataset downloads and model trains seamlessly on initialization without repeating overhead on subsequent interactions.
